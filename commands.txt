Commands for labs 2-4

Before running the project

1. Create a local environment file:
   Copy-Item .env.example .env

2. Put local database values into .env.
   Do not commit .env and do not show it in screenshots.


Lab 2: Docker + FastAPI + PostgreSQL

1. Go to the project root:
   cd C:\Users\Admin\fastapi-lab1

2. Build the FastAPI Docker image:
   docker compose build

3. Start the web and db containers:
   docker compose up -d

4. Check running containers:
   docker compose ps

5. View FastAPI container logs:
   docker compose logs -f web

6. Check Poetry dependencies inside the container:
   docker compose exec web poetry show

7. Run development mode with reload:
   docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build


Lab 3: CRUD with Postman

1. Start the project:
   docker compose up -d

2. For safe Postman screenshots, prefer endpoints without private data:
   GET http://localhost:8000/teams/
   GET http://localhost:8000/categories/
   GET http://localhost:8000/motorcycles/

3. If you screenshot /users/, hide emails, passwords, Authorization headers, Cookie headers, and any private values.

4. Example POST /teams/:
   Method: POST
   URL: http://localhost:8000/teams/
   Body JSON:
   {
     "name": "KTM",
     "country": "Austria"
   }

5. If this team already exists, the API returns 409 Conflict. That is expected.


Lab 4: PostgreSQL + Alembic + async SQLAlchemy

1. Start the database and API:
   docker compose up -d

2. Migrations run automatically in entrypoint.sh:
   poetry run alembic upgrade head

3. Run migrations manually if needed:
   docker compose exec web poetry run alembic upgrade head

4. Check tables in PostgreSQL without showing credentials:
   docker compose exec db sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "\dt"'

5. For database screenshots, show table structure or safe tables:
   docker compose exec db sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "SELECT id, name, country FROM teams;"'
   docker compose exec db sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "SELECT id, name FROM categories;"'

6. Do not show these values in screenshots:
   .env
   DB_PASS
   POSTGRES_PASSWORD
   database connection strings
   Authorization headers
   Cookie headers
   real emails
   user passwords
   API keys or tokens
   private hosts or IP addresses

7. Stop containers:
   docker compose down
